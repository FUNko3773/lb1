Библиотека
Учебное веб-приложение для читателей, которое объединяет функции каталога книг и личного списка чтения.

Назначение проекта
Проект представляет собой демонстрационную версию веб-сайта библиотеки, предназначенную для выбора книг и формирования личного списка чтения. Главная цель сайта — предоставить пользователю простую, понятную и быструю точку для планирования чтения и учёта прочитанного.
